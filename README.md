# hxwl-08 酒会同场盲品赛 · 评分与校准系统

双评委独立打分的盲品赛管理：分差达两级名次暂扣并转主评校准，校准写明依据后排名更新，赛果确认当天冻结，申诉仅追加备注。

## 技术栈

React + Vite + TypeScript + CSS（localStorage 本地存档）

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5108

## 流程规则

1. 每款酒由两位评委独立打分，双方提交前评语与分数互不可见（评分页只显示盲品编号）。
2. 双方分差达到 2 级时，该酒名次先不公开，转主评校准。
3. 主评校准必须写明依据并给出最终分；原始意见与初分保留，全程可追溯。
4. 校准完成后排名才更新；未校准的暂扣酒款不进入榜单。
5. 全部酒款定案后可确认赛果，确认后当天冻结；选手申诉只补备注，名次不再变化。

## 目录结构（资料 / 规则 / 存档 / 页面分开整理）

```
src/
  types.ts            领域类型（评分、校准、申诉、赛次）
  data/
    wines.ts          酒款资料与评委名单
    rules.ts          复核规则（等级制、分差阈值、冻结策略）
    seed.ts           初始赛次数据
  lib/
    engine.ts         分差判定、最终分、排名逻辑
    storage.ts        本地存档（localStorage 读写、导出、重置）
  pages/              总览 / 评分 / 校准 / 排名 / 赛果申诉 / 酒款 / 规则 / 存档
  App.tsx             页签导航与状态持久化
```

重新打开页面会自动恢复未决赛次，可接着评分或校准。
