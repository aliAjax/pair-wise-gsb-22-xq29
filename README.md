# 同场盲品记分 · 双评委校准系统

酒会同场盲品赛的本地记分工具：两位评委独立打分、分差两级交主评校准、确认后当天冻结。纯前端应用，数据存本机浏览器，不依赖后端。

## 流程与规则

1. **双评委独立打分**：评委 A / B 各自选 1–5 级（淘汰 / 普通 / 良好 / 优秀 / 极佳）并写评语；提交前互相看不到内容，只能看到对方「已提交 / 未提交」。
2. **双交后可见评语**：两人都提交后才展示对方评语与初分；此时双方均不可撤回，初分永久留痕。
3. **分差两级挂校准**：分差 ≥ 2 级的酒款名次**暂不公开**，进入「主评校准」队列。
4. **主评校准**：必须写明依据并给最终分；校准完成后名次才更新。确认赛果前允许修订，旧版自动留痕。
5. **确认即冻结**：所有条目生效后才能确认赛果。冻结后名次、初分、校准结果均不可改；选手申诉**只追加备注**。
6. **接着未决赛次**：全部操作实时写入 localStorage，关闭重开后通过「继续未决」直接回到校准队列或未完成赛次。

## 页面划分

| 页面 | 职责 |
| --- | --- |
| 酒会总览 | 进度、复核规则、新建/切换酒会、导入导出本地存档 |
| 酒款资料 | 赛次（flight）与酒款身份信息；盲品阶段对评委隐藏 |
| 盲品打分 | 双评委面板、五级量表、双交对比 |
| 主评校准 | 分歧条目队列、依据与最终分、校准沿革 |
| 名次 | 赛次排名（暂缓公开区）、确认冻结、申诉备注、身份揭示开关 |

## 代码组织（资料 / 规则 / 存档 / 页面分开）

```
src/
├── types.ts              # 领域模型
├── rules/scoring.ts      # 复核规则：分级、分差、状态机、排名
├── storage/persist.ts    # 本地存档：localStorage、导入导出、自检
├── storage/sample.ts     # 示例酒款与会次
├── state/store.tsx       # 状态与全部写操作（即时落盘）
├── components/ui.tsx     # 通用组件
└── pages/                # 五个页面
```

## 本地运行

```bash
npm install
npm run dev      # http://localhost:5108
npm run build    # 类型检查 + 生产构建
```

首次打开自动载入一份覆盖全部状态的示例数据（待双交 / 初分生效 / 待校准 / 已校准 / 已冻结归档）。可在「酒会总览」中导出 JSON 备份、在其他机器导入继续使用（ID 自动重映射，不冲突）。
